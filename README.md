# Car Inventory Application (.NET / C#)

This project is a Windows Forms-based inventory management application developed using C# and .NET. The application allows users to manage and track vehicle inventory through a graphical user interface.

## Features
- Add new vehicles to inventory
- View and manage existing inventory
- Edit and update vehicle information
- User-friendly interface using Windows Forms
- Event-driven functionality for user interactions

## Technologies Used
- C#
- .NET Framework
- Windows Forms (GUI)
- Object-Oriented Programming

## Project Structure
- Form-based UI for user interaction
- Backend logic implemented using C# classes
- Organized using Visual Studio solution and project files

## How to Run
1. Open the solution file (`.sln`) in Visual Studio
2. Build the project
3. Run the application
